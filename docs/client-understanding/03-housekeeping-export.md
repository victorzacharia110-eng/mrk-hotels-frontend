# Understanding the Update · 3 — Housekeeping: A Reliable Spreadsheet Export

**For the management and staff of MRK Hotels** — **5 September 2026**

---

## 1. What was the problem?

Downloading the housekeeping task list to **Excel / CSV** produced a messy file: columns did not line up, important details were missing from cells, and the column order seemed random.

**What that meant for you:**

- Daily reports and handover sheets needed manual fixing before they could be used.
- Managers could not trust the numbers straight out of the download.
- The file was not a proper record of room cleaning status.

## 2. What did we change?

- The system now prepares the data in a **clean, flat layout** before exporting.
- The export always contains the same **ten well-named columns**, in a sensible order:

| Column | What it tells you |
| --- | --- |
| Room | Room number |
| Room type | Single, double, suite, etc. |
| Pax | Guests currently in the room |
| Housekeeping status | Clean, dirty, in progress, etc. |
| Assigned to | Staff member responsible |
| Room status | Occupied, vacant, arriving today, etc. |
| Arrival | Guest expected to arrive |
| Departure | Guest expected to leave |
| Nights | Length of stay |
| Status | Task status |

## 3. Why it matters to you

- **Reports you can trust.** The download is complete and correctly aligned, with no hidden or empty columns.
- **Ready-to-use handover sheets.** Print or share the file directly — no rework.
- **Better daily oversight.** One clear snapshot of every room's cleaning and occupancy state.

## 4. What you will see in the app

- On the **Housekeeping** page, the export button now delivers a tidy spreadsheet every time.
- Nothing else about the housekeeping screen changes.

## 5. Summary

| Question | Answer |
| --- | --- |
| Where do I export from? | The Housekeeping task list page (Excel/CSV button) |
| What will the file look like? | Ten clean, labelled columns in a fixed order |
| Does it require training? | No — the same button, a better result |
| Does the format change? | No — still Excel/CSV, just correctly filled |
