All review areas are now closed. The follow-up pass finished the stock-count date filter, category column, item search, variance reasons and Save guard, and replaced department transfers with outlet-to-outlet transfers, a full item picker, SI-unit conversion, Cost Value and the three signature lines. 1. Dashboard and navigation

These fixes cover the top bar, the outlet picker, the dashboard shortcuts and the low-stock summary.

1
Top-right profile menu
Fixed
Dashboard
THE PROBLEMLog out, user manual, language and dark mode were split around the top bar, and the words STORE MANAGER took space without adding an action.
THE FIXThe label is gone. The avatar now opens one menu with User Manual, My Profile, Dark Mode, English / Swahili and Log Out, matching the front-desk panel.
WHERE TO FIND IT
Store Manager→Top-right avatar→User Manual / My Profile / Dark Mode / EN–SW / Log Out
2
Outlet selection only when it matters
Fixed
Dashboard
THE PROBLEMThe outlet picker appeared even when the property had only one store outlet, where it cannot change anything.
THE FIXThe header picker and the post-login outlet gate now appear only when the property has more than one outlet. A single outlet is selected silently. The Stock Transfers link is also hidden until a second outlet exists.
WHERE TO FIND IT
Store Manager→Header outlet picker→Shown only for multi-outlet properties
3
Dashboard quick actions
Fixed
Dashboard
THE PROBLEMThe dashboard offered New Requisition, which sends the store manager into the requisition screen even though the store receives requisitions rather than writing them.
THE FIXThe button is replaced with New Purchase Order. New Item, Record Goods Received and New Supplier remain, so the four shortcuts match the store manager’s actual work.
WHERE TO FIND IT
Store Manager → Dashboard→Quick actions→New Purchase Order
4
Low-stock table length
Fixed
Dashboard
THE PROBLEMThe dashboard low-stock table was long and pushed the rest of the page down.
THE FIXThe dashboard shows the first 5 low-stock items. View all opens the full Low Stock page. The KPI cards are clickable and lead to the relevant lists.
WHERE TO FIND IT
Dashboard→Low Stock alerts→First 5 rows→View all → Low Stock page

2. Purchase orders

Purchase orders now follow the business date, use a simple sequential reference, offer every registered item and print voided orders clearly.

5
Business date and delivery date
Fixed
Purchase Orders
THE PROBLEMThe purchase-order business date had to be set by hand, and the X beside the date cleared it and crashed the flow. The delivery date had the same clear control.
THE FIXThe business date now defaults from the shared day-close date, follows the calendar, and has no clear X. The list is filtered by the selected date. The delivery-date X is also removed and the calendar stays fully visible as DD/MM/YYYY.
WHERE TO FIND IT
Store Manager → Purchase Orders→Business date / Delivery date→No clear X→List follows the selected date
6
Purchase-order numbering
Fixed
Purchase Orders
THE PROBLEMReferences used the property code and a random-looking suffix, for example PO-MGH-2026-0016K.
THE FIXPurchase orders now use a sequential per-hotel, per-year reference: PO-2026-0001. The format continues cleanly into the next year.
WHERE TO FIND IT
Purchase Orders→New purchase order→Save→Reference: PO-2026-0001
7
Item picker and voided print
Fixed
Purchase Orders
THE PROBLEMSome registered items could not be found in the purchase-order dropdown, and a voided purchase order printed like a normal one.
THE FIXThe item picker loads every registered item through the paginated inventory endpoint and remains searchable. A voided order now prints with a clear VOIDED stamp and the void reason, so it cannot be mistaken for a live order.
WHERE TO FIND IT
New Purchase Order→Add item → search any registered item→Print a voided PO → VOIDED stamp

3. Goods received

Goods received is searchable by supplier, follows the business date, uses the GRN-year-number format and only offers orders that can still receive stock.

8
Search by supplier
Fixed
Goods Received
THE PROBLEMThe goods-received search did not find a GRN by supplier name, which is easier to remember than the reference number.
THE FIXSearch now runs on the server and matches GRN number, supplier name and purchase-order number. It is debounced and loads up to 100 records per request, then filters the result set in the table.
WHERE TO FIND IT
Store Manager → Goods Received→Search→Type the supplier name→Open the GRN
9
Business date and calendar
Fixed
Goods Received
THE PROBLEMThe goods-received business date did not follow the day close, was cut off as “OCT 22…”, and had a clear X that disrupted the page.
THE FIXThe business date now follows the shared day close, is fully visible as DD/MM/YYYY, has no clear X, and filters the GRN list to the selected date.
WHERE TO FIND IT
Goods Received→Business date→Full date shown→List follows the date
10
GRN numbering
Fixed
Goods Received
THE PROBLEMGRN references used the property code and an inconsistent suffix, for example GRN-MGH-2026-00153.
THE FIXNew GRNs use GRN-2026-0001: GRN, business year, then a four-digit sequential number that resets each year.
WHERE TO FIND IT
Goods Received→Record goods received→Save→Reference: GRN-2026-0001
11
Purchase-order dropdown
Fixed
Goods Received
THE PROBLEMThe receive screen listed every purchase order, including orders that were already received, cancelled or voided.
THE FIXThe dropdown now offers only orders that can still receive stock: pending, manager_approved, approved and partially_received. Closed orders are excluded.
WHERE TO FIND IT
Record Goods Received→Purchase order dropdown→Only open orders appear

4. Expenses

Expenses now sit on one business date, use registered categories, carry a reference and particular, and are voided with a reason.

12
One business date
Fixed
Expenses
THE PROBLEMThe expense calendar had blank intervals, so the user had to set the date by hand, and the list was not tied to the date selected.
THE FIXThe interval picker is replaced by one calendar that defaults to the shared day-close date. The expense list is filtered by that date and the total follows the same selection.
WHERE TO FIND IT
Store Manager → Expenses→Business date→List and total follow the date
13
Categories and registration
Fixed
Expenses
THE PROBLEMThe category dropdown was cramped, and there was no clear place to register the categories that should appear in it.
THE FIXThe category control is a searchable selector with room for the full label. Categories are registered in Back Office → Expense Categories; the expense form also has a New category shortcut. The same list feeds validation and every expense dropdown.
WHERE TO FIND IT
Expenses → Category→New category→or Back Office → Expense Categories
14
Void with a reason, not “type DELETE”
Fixed
Expenses
THE PROBLEMDeleting an expense required typing the word DELETE, gave no audit reason, and could not be done in bulk.
THE FIXThe delete action is now a void. It asks for a reason, keeps the record with void metadata, removes it from totals through the not-voided scope, and supports bulk void from the row selection.
WHERE TO FIND IT
Expenses→Select a row / rows→Delete selected→Enter the void reason→Confirm
15
Particular, reference and search
Fixed
Expenses
THE PROBLEMEach expense had no reference code and no dedicated particular column; search only covered the description.
THE FIXExpenses now carry EXP-2026-0001 references and a Particular column. Search matches description, particular and reference, so a receipt can be found by any of them.
WHERE TO FIND IT
Expenses→Reference / Particular columns→Search any of the three

5. Cash register

The register now follows the business date, exposes cash expenses for that date, and records every float with its own reference.

16
Business date and cash expenses
Fixed
Cash Register
THE PROBLEMThe cash register had no business-date calendar, and the cash-expense summary was not tied to the selected date.
THE FIXA calendar now defaults to the shared day-close date. The cash-expense table and its total are loaded for that date, so float − expenses = remaining stays visible and consistent.
WHERE TO FIND IT
Store Manager → Cash Register→Business date→Cash expenses for that date
17
Floats and the removed Current Cash
Fixed
Cash Register
THE PROBLEMThere was no way to add a float, floats had no reference, and Current Cash duplicated figures without a clear purpose.
THE FIXCurrent Cash is removed. An Add Float button records each top-up with a sequential FLT-2026-0001 reference. The summary shows Opening Float, Float Added, Cash Expenses and Remaining Float. Expected cash and remaining cash include the floats.
WHERE TO FIND IT
Cash Register → Add Float→Amount + optional reference→Float pills and KPI update→Close register shows remaining float

6. Department indents

The requisition and indent-forward screens now share one date, an outlet filter, a Pending/Complete switch, an In Stock column and a single detail view for every action.

18
One business date
Fixed
Department Indents
THE PROBLEMThe date range used two calendars and a clear X, and did not follow the day close.
THE FIXThe page now has one calendar, no clear X, and the date is synced to the shared business date. The same date drives both the requisition and indent-forward lists.
WHERE TO FIND IT
Store Manager → Department Indents→Business date→One calendar, synced to day close
19
Pending / Complete, outlet and columns
Fixed
Department Indents
THE PROBLEMStatus was a dropdown, there was no outlet filter, and every row carried an Action column that crowded the table.
THE FIXStatus is a Pending / Complete segmented filter. Pending covers draft and pending; Complete covers forwarded, approved, fulfilled, rejected and voided. An outlet dropdown filters the list. The table shows S/N, date, department, outlet, items, cost value and status — no Action column.
WHERE TO FIND IT
Department Indents→Pending / Complete→Outlet filter→Click the S/N reference to open a row
20
Requested, In Stock and supplied
Fixed
Department Indents
THE PROBLEMThe Answer & Forward screen showed only Requested and Reply, so the store keeper could not see what was actually on the shelf.
THE FIXAn IN STOCK column now sits between Requested and Supplied. It reads the selected outlet’s shelf balance, so the store keeper can answer against real stock.
WHERE TO FIND IT
Department Indents → Inbox→Open a pending request→Answer & Forward→Requested → IN STOCK → Supplied
21
Actions in the detail view
Fixed
Department Indents
THE PROBLEMView and Approve sat beside every row, while the actions that matter were split between the list and the detail screen.
THE FIXThe row action column and the View and Approve actions are removed. Clicking the reference or row opens the detail, where the applicable actions appear: Edit, Send, Recall, Answer & Forward, Accept, Reject, Void and Cancel. Requested by, outlet and cost value are visible in the same view.
WHERE TO FIND IT
Department Indents→Click the S/N reference→Detail actions→Answer & Forward / Accept / Reject / Void / Cancel
22
Cost value
Fixed
Department Indents
THE PROBLEMThe list had no reliable cost value for a requisition, and there was no way to show the value of what was actually sent.
THE FIXEach line now exposes unit cost, requested cost value, supplied cost value and current stock. The list shows the requested value; once a request is forwarded, approved or fulfilled it shows the supplied value. The detail shows the same figure.
WHERE TO FIND IT
Department Indents→Cost value column→Open a forwarded request → supplied value

7. Low stock

Low stock is now a focused reorder screen: no calendar, useful filters, row selection and a hand-off straight into a purchase order.

23
Remove the calendar, add filters
Fixed
Low Stock
THE PROBLEMThe Low Stock page carried a business-date calendar that had no effect, and there was no way to separate out-of-stock items from items below reorder level or by category.
THE FIXThe calendar is removed. Two filters are added: All alerts / Out of stock / Below reorder, plus a searchable category filter. The KPI cards show the counts for each state.
WHERE TO FIND IT
Inventory → Low Stock→Stock filter + Category filter→List narrows immediately
24
Mass reorder to a purchase order
Fixed
Low Stock
THE PROBLEMEach row had a single Reorder action, and it linked to the requisition page instead of creating a purchase order.
THE FIXThe Action column is replaced by row checkboxes and a top Reorder button. Selected items are carried into a new Purchase Order with their quantities pre-filled; the user is no longer sent to a requisition.
WHERE TO FIND IT
Low Stock→Tick the items→Reorder→New Purchase Order opens with the selected items

8. Stock count

Count sheets now have a business date that filters the API and history, a Category column, item-level search, per-variance reasons in a Description tab, a Save guard, TKE numbering, a Saved/Submitted split, autosave and Enter-to-next.

25
Business date on the count page
Fixed
Stock Count
THE PROBLEMThe stock-count page had no business date, so a count could not be tied to the day it belonged to.
THE FIXA business-date calendar defaults from day close. The API filters takes by business_date, and the page opens an active sheet only for the current business day. Selecting an earlier closed day shows that day’s count history instead of reopening a sheet. New counts can only be started on the current business day.
WHERE TO FIND IT
Inventory → Stock Count→Business date→Current-day sheet / earlier-day history
26
Category filter and column
Fixed
Stock Count
THE PROBLEMThe count sheet did not show which category each item belonged to, and categories could not be used to narrow the count.
THE FIXA searchable category filter is on the toolbar and the count table now has a Category column. The Variance and Description tabs show only counted rows that differ from the system.
WHERE TO FIND IT
Stock Count→Category filter / Category column→All rows / Variance / Description
27
TKE numbering
Fixed
Stock Count
THE PROBLEMCount sheets used the property code and an inconsistent suffix, for example TKE-MGH-2026-00079.
THE FIXNew counts use TKE-2026-0001: TKE, business year, then a four-digit sequential number.
WHERE TO FIND IT
Stock Count→New count→Sheet reference: TKE-2026-0001
28
Saved / Submitted and autosave
Fixed
Stock Count
THE PROBLEMThe old OPEN / POSTED status dropdown was unclear, and a browser refresh or power cut could lose manual counts.
THE FIXThe history uses a Saved / Submitted segmented switch. Open sheets are saved; posted and voided sheets are submitted. The active sheet autosaves every 15 seconds and shows the last autosave time.
WHERE TO FIND IT
Stock Count→Saved / Submitted→Autosave indicator→Counts survive a refresh
29
Save, Submit, Enter and variance notes
Fixed
Stock Count
THE PROBLEMSave also triggered Submit, Enter did not move between count inputs, and there was nowhere to explain a variance.
THE FIXSave now only saves and Submit posts the take. Enter moves to the next quantity input. The Description tab lists only differing rows and gives each one a Variance reason field. Save is disabled until a count or reason changes, and autosave only writes when the sheet is dirty.
WHERE TO FIND IT
Stock Count→Enter a count → Enter→Description tab → Reason→Save Counted Quantities vs Submit
30
Search on the count page
Fixed
Stock Count
THE PROBLEMThe search bar did not help locate an item inside a long count sheet.
THE FIXThe toolbar search filters the take history, and a separate search above the active sheet filters its item rows live by item name, category and description. The sheet is paginated 20 rows at a time so a long count stays usable.
WHERE TO FIND IT
Stock Count→Open sheet→Item search→Type an item name or category

9. Stock adjustment

Stock adjustments are now sheet-based documents with a reason filter, AD-WS / AD-CM / AD numbering, a printable signature block, share and void.

31
Calendar, type and voided filters
Fixed
Stock Adjustment
THE PROBLEMThe old page was a per-item workbench. It had no business date, no reason filter and no way to see only voided sheets.
THE FIXThe page now has one business-date calendar synced to day close, a type filter (All / Wastage / Consumption / Adjustment), a search box and an All / Voided segmented filter.
WHERE TO FIND IT
Inventory → Stock Adjustment→Business date→Type filter→All / Voided
32
Add a sheet from the top right
Fixed
Stock Adjustment
THE PROBLEMThere was no single place to create a stock-adjustment document, choose its reason and give the reason for each item.
THE FIXAdd sits at the top right. It opens a wide sheet with a type dropdown, Items and Description tabs, a searchable item picker, a quantity/current-level panel and a per-line reason. Adjustment type treats the entered quantity as the new absolute level; wastage and consumption remove the entered quantity.
WHERE TO FIND IT
Stock Adjustment → Add→Choose type→Add item + quantity + reason→Description tab→Save
33
The sheet list
Fixed
Stock Adjustment
THE PROBLEMThe previous table listed individual stock items instead of the adjustment sheets that were actually created.
THE FIXThe list now shows S/N (clickable reference), date, type, item count, cost value and status. Clicking the reference opens the sheet, its before/after quantities and its per-line notes. Voided sheets show the void reason.
WHERE TO FIND IT
Stock Adjustment→Click the AD reference→Sheet detail with before / after / cost
34
AD-WS / AD-CM / AD numbering
Fixed
Stock Adjustment
THE PROBLEMAdjusted items appeared in the ledger without a reference that said which adjustment sheet caused them.
THE FIXEach sheet gets a sequential reference: AD-WS-2026-0001 for wastage, AD-CM-2026-0001 for consumption and AD-2026-0001 for a manual reset. Stock movements point back to the sheet, so the ledger can be traced to the document.
WHERE TO FIND IT
Stock Adjustment→Save a sheet→Reference: AD-WS / AD-CM / AD
35
Print, share, void and audit
Fixed
Stock Adjustment
THE PROBLEMThere was no printable sheet with signature space, no way to share it, and no controlled way to reverse a wrong adjustment.
THE FIXThe detail view has Print (creator, supervisor and authorized-by signature lines, plus a VOIDED banner), Share (API email to a chosen address) and Void (required reason). Voiding reverses every line by its before/after difference and writes an audit entry.
WHERE TO FIND IT
Open an adjustment sheet→Print / Share / Void→Void requires a reason
The Share action currently sends a plain-text email summary. A PDF attachment can be added if the client wants the printed sheet itself in the mailbox.
36
Wider sheet and ledger visibility
Fixed
Stock Adjustment
THE PROBLEMThe adjustment area was cramped compared with Purchase Orders, and the stock ledger did not make the adjustment easy to identify.
THE FIXThe sheet opens in a 1180px modal with a scrollable item table, like the purchase-order screen. The stock ledger records the movement type as adjustment and carries the sheet reference, business date and time.
WHERE TO FIND IT
Stock Adjustment→Open a sheet→Wide Items / Description layout→Stock ledger → adjustment reference

10. Stock transfers

Transfers are hidden for single-outlet properties and now move stock from outlet to outlet. They follow the business date, use DRAFT/SENT and ST numbering, show Cost Value, convert SI units, and can be printed with three signatures, shared or voided.

37
Only when there is more than one outlet
Fixed
Stock Transfers
THE PROBLEMThe Stock Transfers page was always visible, even for a property that had only one store outlet and therefore nothing to transfer to.
THE FIXThe page and its navigation item are hidden unless the property has more than one outlet. A single-outlet property sees an explanatory message instead of an unusable form.
WHERE TO FIND IT
Store Manager→Inventory→Stock Transfers appears only for multi-outlet properties
38
Outlet-to-outlet, not department-to-department
Fixed
Stock Transfers
THE PROBLEMThe review asked for transfers between outlet stores, not between unrelated departments such as kitchen and bar.
THE FIXThe form now uses searchable From outlet and To outlet pickers. The API stores both outlet ids and resolves each outlet to its linked stock shelf for the ledger, keeping the ledger correct while the document reads outlet-to-outlet. Older department ids remain accepted as a fallback.
WHERE TO FIND IT
Stock Transfers→Add→From outlet / To outlet
39
Business date and DRAFT / SENT
Fixed
Stock Transfers
THE PROBLEMThe page had no business date, and the status model did not match the two states the store uses.
THE FIXA calendar defaults from day close and filters the list by date. The visible statuses are DRAFT and SENT; a sent transfer is stored as completed by the API and displayed as SENT.
WHERE TO FIND IT
Stock Transfers→Business date→Status: DRAFT / SENT
40
ST numbering and save/send
Fixed
Stock Transfers
THE PROBLEMTransfer references used an unrelated prefix, and Save/Send did not cleanly separate a draft from a dispatched transfer.
THE FIXNew transfers use ST-2026-0001. Save Draft keeps the transfer editable; Save & Send dispatches it immediately. A draft can also be sent later from its row.
WHERE TO FIND IT
Stock Transfers → Add→Save Draft / Save & Send→Reference: ST-2026-0001
41
Item picker
Fixed
Stock Transfers
THE PROBLEMThe item dropdown did not behave like the purchase-order picker: it was not searchable and did not expose the full item list or cost information.
THE FIXThe picker uses the paginated all-items loader, so every registered item is reachable. Each option shows category, shelf stock and unit cost. The form offers the item’s SI units, converts the entered quantity to base units, and previews the live cost (base quantity × unit cost) before saving.
WHERE TO FIND IT
Stock Transfers → Add→Item → Unit→Quantity + Notes→Live stock and cost preview
42
List, print and share
Fixed
Stock Transfers
THE PROBLEMThe old table showed individual item rows, and the transfer sheet had no share, void or signature layout.
THE FIXThe list shows S/N, reference, date, item summary, from outlet, to outlet, quantity, Cost Value and status. Print includes unit cost, line cost, total, and a VOIDED banner when applicable. The signature block reads Creator, Supervisor and Authorized by. Share uses the device share sheet or email; Void requires a reason.
WHERE TO FIND IT
Stock Transfers→Cost Value column→Row Print→Creator / Supervisor / Authorized by
