RECEPTION PANEL CHANGES GUIDE

For Non-Technical Staff

1. DASHBOARD - TOP TOOLBAR

A. Profile (Name Only)

BEFORE: Name + Role | AFTER: Name only
  • Location: Top-right corner of the Dashboard
  • What changed: Profile chip shows only your name and initials - no job title/role shown
→ Dashboard > Top Bar (Right Side) > Profile Chip

B. Business Date (Replaces "TODAY")

BEFORE: "TODAY" | AFTER: "BUSINESS DATE"
  • Location: Top toolbar, left side
  • Shows: Hotel's current business date (not your device calendar date)
  • Behavior: Moves forward automatically ONLY when previous business day had NO activity (no reservations, no checked-in guests). If there is activity, it stays until Night Audit completes.
→ Dashboard > Top Toolbar (Left) > BUSINESS DATE Button

C. Search Bar With Results Dropdown

BEFORE: Search not working properly | AFTER: Working with clickable results
  • Location: Top toolbar, middle-right (magnifying glass)
  • How to use: Type at least 2 characters (Guest Name, Room Number, or Booking Reference)
  • Result: Dropdown appears showing matching stays and rooms
  • Action: Click any result to jump directly to that stay/room
→ Dashboard > Top Toolbar > Search Box > Type 2+ Characters > Results Dropdown

2. NEW BOOKING TAB

How to open: Click + New Booking on the Dashboard

A. Room Dropdown Filters By Room Type

BEFORE: Showed all room types | AFTER: Shows only rooms of the same room type
  • Location: New Booking Form > Room dropdown
  • Example: If you select a Suite, only available Suites appear - not Standard/Double rooms
→ Dashboard > + New Booking > Room Field > Dropdown (Same Room Type Only)

B. City Field Is Searchable

BEFORE: Hard to select | AFTER: Type-to-search
  • Location: New Booking Form > City field
  • How to use: Click dropdown and type a few letters - list filters automatically
→ Dashboard > + New Booking > City Field > Type To Search

C. Auto Total Badge Removed

BEFORE: Extra "AUTO TOTAL" badge outside box | AFTER: Clean, inside form only
  • Location: New Booking Form > Totals section
  • What changed: Removed the floating Auto Total badge outside the CSS box
→ Dashboard > + New Booking > Totals Section (Clean Layout)

D. Walk In vs Reservation Buttons (SPLIT BUTTONS)

BEFORE: One "CREATE BOOKING" button | AFTER: Split into WALK IN | RESERVATION
  • Current BUSINESS DATE: Shows TWO buttons - WALK IN (Green) and RESERVATION
    • WALK IN: Creates booking AND checks guest in immediately (Room turns GREEN/Occupied)
    • RESERVATION: Creates reservation only (Room stays RED/Reserved, wait for Check-In)
  • FUTURE DATES: Shows ONLY RESERVATION button (No Walk-In)
→ Dashboard > + New Booking > Bottom Buttons (Split Based On Business Date)

3. GROUP BOOKINGS (Multi-Room Bookings)

Location: New Booking Form > Booking Type Dropdown

  • What it is: Create multiple rooms under one group/party with a shared booking reference
  • How to use: Set Booking Type to Group, select 2+ rooms (Room Selections), set Primary Room, fill guest details, Save
  • On Reservation List: Group bookings show a Group Badge showing number of rooms in the party
  • Cancellation: Cancel Modal lets you cancel the Whole Group OR Selected Rooms only
→ Dashboard > + New Booking > Booking Type = Group > Select 2+ Rooms > Set Primary Room > Save

4. FOLIO OPERATIONS - Correct Related Folio Balance

  • Location: Folio View > Settle to Creditors (when viewing a Related/Split Folio)
  • What changed: When viewing a related folio (from Split/Cut), the settlement amount shown is the Related Folio's Balance - NOT the main/current folio balance
→ Dashboard > Open Stay (With Split/Cut Folios) > View Related Folio > Folio Operations > Settle To Creditors

5. MAINTENANCE ROOMS - Cannot Be Booked

  • What changed: Rooms marked as Maintenance are excluded from booking completely
  • Check: Maintenance rooms do NOT appear in the Room Dropdown when creating a new booking
→ Dashboard > + New Booking > Room Dropdown (Maintenance Rooms Excluded)

6. INVOICE - Guest & Staff Signatures

  • Location: Printed Invoice (Print Invoice Breakdown)
  • What added: Signature spaces at the bottom of the printed invoice
  • Lines shown: 1) Guest signature & date | 2) Authorized signature & stamp
→ Dashboard > Open Stay > Print > Print Invoice Breakdown > Bottom Of Page (Signature Lines)

7. CHECK OUT - Extra Safety Checks

A. All Related Folios Must Be Settled

  • If stay has Split/Cut related folios, ALL related folio balances must be fully settled before checkout
  • System blocks checkout if any related folio has outstanding balance (with clear message)

B. Cannot Check Out With Future Departure Date

  • BLOCKED: If Check Out Date is AFTER current BUSINESS DATE
  • ALLOWED: Overdue stays (departure date already passed)
  • Rule: Checkout date must match/be on or before Business Date
→ Dashboard > Open Checked-In Stay > Check Out (Validates Both Rules)

8. VOID RESERVATION

A. Management Only

  • Only visible to: Manager, Hotel Admin, Owner, or Superadmin
  • Receptionists do NOT see the "Void Reservation" option
→ Dashboard > Open Reservation > Three Dots (⋯) Menu > Void Reservation (If Authorized)

B. Reason Required (No Guest Name)

  • Now asks for "Reason for voiding" (text box)
  • REQUIRED: Must type a reason to confirm (No longer asks for guest name)

C. Voided Reservations Go To Reports (Removed From Dashboard)

  • After voiding successfully, reservation is COMPLETELY REMOVED from Dashboard (Not left red)
  • Find voided records at: Reports > Report Browser > Void Reservations
  • Report shows: Booking Ref, Guest, Room, Dates, Amounts, Voided On, Voided By, Reason
→ Reports > Report Browser > Void Reservations

9. SEQUENCING - Automatic Sequential References

  • Reservations: Automatic sequential Booking Reference (BK-...)
  • Night Audit → Manual Transactions (Insert Transaction): Sequential ADJ-... reference
  • Folio Entries & Refunds: Sequential FLX-... references
  • Where to see: Reservation Details, Night Audit → Transactions, Folio View, Void Reservations Report
→ Reservation Details / Night Audit → Transactions / Folio View / Void Reservations Report
